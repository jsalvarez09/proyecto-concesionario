# 🚗 Motors And Dealers - Plataforma de Venta de Vehículos

Bienvenido al repositorio de **Motors And Dealers**, una aplicación web completa para la gestión y venta de vehículos. Este proyecto permite a los usuarios ver un catálogo de autos, registrarse y, dependiendo de su rol, gestionar el inventario.

## 📋 Características Principales

* **Roles de Usuario:**
    * **Cliente:** Puede ver el catálogo y detalles de los vehículos.
    * **Vendedor/Admin:** Puede publicar, editar, eliminar y marcar vehículos como vendidos.
* **Gestión de Vehículos:** CRUD completo (Crear, Leer, Actualizar, Borrar) con carga de imágenes.
* **Panel de Control:** Dashboard con estadísticas de ventas y vehículos activos.
* **Seguridad:** Login seguro con contraseñas encriptadas (Hash) y protección contra inyecciones SQL.

## 🛠️ Tecnologías Usadas

* **Frontend:** HTML5, CSS3 (Diseño Responsive), JavaScript.
* **Backend:** PHP (Nativo).
* **Base de Datos:** MySQL.
* **Servidor Local:** XAMPP (Apache).

## 🚀 Instalación y Configuración

1.  **Clonar el repositorio** o descargar el código.
2.  **Base de Datos:**
    * Abre PHPMyAdmin (o tu gestor SQL favorito).
    * Crea una base de datos llamada `concesionario_db`.
    * Importa el archivo `database.sql` que encontrarás en la carpeta raíz de este proyecto.
3.  **Ejecutar:**
    * Coloca la carpeta del proyecto en `htdocs` (si usas XAMPP).
    * Abre tu navegador e ingresa a `http://localhost/NOMBRE_DE_TU_CARPETA/`.
